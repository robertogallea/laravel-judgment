# v1 scope and package identity

Package `robertogallea/laravel-judgment`, namespace `RobertoGallea\Judgment`, PHP ≥ 8.3, Laravel 12+. v1 ships: Judgment definitions (Likelihood/Classification/Rating, untrusted-Evidence marker, optional Evidence language), pure Decisions returning Outcome enums with opt-in Review, immutable Assessments with package Confidence and Provenance, the `Judge` facade/contract (sync `assess`, queued `dispatch`, Unassessed on failure), the Engine contract with Jev and fake drivers, persisted records with pruning and a Subject relation, the Review/Resolution lifecycle and events, opt-in caching, fakes and assertions, and `make:judgment` / `make:decision` / `judgment:eval`. Deferred: Judgment pipelines, a PHPStan extension, a Pulse card, a Filament review UI, Review deadlines, additional Engines. Evidence is not translated: Jev is English-first, so language is recorded per Assessment and surfaced by Calibration instead of hidden behind an unaudited translation step. Calibration (`judgment:eval`) is not deferrable: the Jev reality-check prototype showed probabilities are asymmetric per Question (clear abuse 0.69–0.90, ambiguous 0.12–0.49), so generic threshold bands are wrong and every Decision must be calibrated. For the same reason, generated Judgment/Decision stubs carry no default threshold numbers.
